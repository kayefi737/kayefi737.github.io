🛡️ AegisScan Featured

Grade any website's external security posture in ~10 seconds.

A FastAPI web-security scanner that runs 20+ passive, read-only checks across nine categories, computes a transparent A+→F grade, and returns a report where every failure carries the exact fix and its OWASP Top-10 mapping. Built to run with one command and zero managed services.

  • Async, concurrent scan engine (asyncio.gather) of pure check functions
  • SSRF guard that resolves and rejects private / loopback / reserved IPs
  • Published, reproducible weighted scoring rubric served at /api/meta
  • Auto-generated OpenAPI / Swagger docs at /docs
  • JWT + bcrypt auth; guest and authenticated scan flows
  • JSON / HTML / PDF reports (reportlab, no system libraries)
  • Offline pytest suite; CI matrix on Python 3.11 / 3.12 / 3.13
  • SQLite by default, swap to Postgres with one env var
